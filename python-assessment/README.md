# Python Assessment — `main.py`

A set of 25 Python coding exercises covering core language fundamentals. Each question is answered inline using standard Python with no external dependencies.

## Sections

### Section A — Strings (Q1–Q5)
| Q | Task |
|---|------|
| Q1 | Reverse a string without slicing |
| Q2 | Find the first non-repeating character |
| Q3 | Check if a string is a palindrome |
| Q4 | Count frequency of each character |
| Q5 | Remove duplicate characters while preserving order |

### Section B — Lists (Q6–Q10)
| Q | Task |
|---|------|
| Q6 | Remove duplicates from a list without `set()` |
| Q7 | Find the second largest number |
| Q8 | Find all duplicate elements |
| Q9 | Rotate a list by K positions |
| Q10 | Find the intersection of two lists |

### Section C — Dictionary (Q11–Q15)
| Q | Task |
|---|------|
| Q11 | Count frequency of elements using a dict |
| Q12 | Find the key with the maximum value |
| Q13 | Reverse a dictionary (swap keys and values) |
| Q14 | Merge two dictionaries |
| Q15 | Count word frequency in a sentence |

### Section D — Loops (Q16–Q20)
| Q | Task |
|---|------|
| Q16 | Print a `**` pattern |
| Q17 | Print multiplication table for a given number |
| Q18 | Find factorial using a `for` loop |
| Q19 | Find all prime numbers between 1 and 100 |
| Q20 | Generate Fibonacci series up to N terms |

### Section E — Interview Coding Questions (Q21–Q25)
| Q | Task |
|---|------|
| Q21 | Find the first non-repeating number in a list |
| Q22 | Find the Nth non-repeating number in a list |
| Q23 | Check if two strings are anagrams |
| Q24 | Find the missing number from an array |
| Q25 | Find the top-occurring element in a list |

## How to Run

> **Note:** `main.py` runs all 25 questions sequentially. Questions that use `input()` will pause and wait for keyboard input.

```bash
cd python-assessment
python main.py
```
